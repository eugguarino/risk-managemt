# risk-managemt

Applicazione web statica per creare una matrice di rischio 3×3 con tre livelli di probabilità e impatto (basso, medio, alto).

## Come eseguire
1. Apri una shell nella cartella del progetto.
2. Avvia un piccolo server locale, ad esempio con Python:
   ```bash
   python -m http.server 8000
   ```
3. Visita [http://localhost:8000](http://localhost:8000) dal browser per utilizzare lo strumento.
